# 10 - 书架与小说详情：核心业务页面

书架页面是用户管理收藏小说的核心入口，包含 6 个分页 TabBar、搜索模式和多选操作（移动/删除）。novel_detail 是最复杂的业务页面，展示模糊背景封面、小说信息、目录列表、继续阅读 FAB 和章节批量缓存操作。detail 的控制器管理小说加载、目录展示、章节多选、缓存任务和书架操作，是整个应用业务逻辑最密集的地方。

### 2.4 BookshelfContentController — 单个分类

```dart
class BookshelfContentController extends GetxController {
  final String classId;
  final BookshelfController _bookshelfController = Get.find();
  final MainController _mainController = Get.find();

  Rxn<Bookshelf> bookshelf = Rxn();
  Rx<PageState> pageState = Rx(PageState.loading);

  @override
  void onReady() {
    super.onReady();
    // 监听本地数据库变化（实时同步）
    DBService.instance.getBookshelfByClassId(classId).listen((bss) async {
      List<BookshelfNovelInfo> list = bss.map((i) =>
        BookshelfNovelInfo(bid: i.bid, aid: i.aid, url: i.url, title: i.title, img: i.img)
      ).toList();

      if (list.isEmpty) {
        bookshelf.value = null;
        pageState.value = PageState.empty;
      } else {
        bookshelf.value = Bookshelf(list: list, classId: classId);
        pageState.value = PageState.success;
      }
    });
  }
}
```

### 3.3 getNovelDetail() — 数据加载完整链路

```
NovelDetailController.onReady()
  │  ① 获取应用支持目录：_supportDir = getApplicationSupportDirectory()

  │

  │
```

```dart
Future<bool> _getNovelDetailByLocal() async {
```

### 3.7 _buildCatalogueSliver() — 目录列表

```dart
Widget _buildCatalogueSliver(BuildContext context) {
  final detail = controller.novelDetail.value!;

  return SliverList(
    delegate: SliverChildBuilderDelegate((context, volumeIndex) {
      // 降序时反转索引
      if (controller.isChapterOrderReversed.value) {
        volumeIndex = detail.catalogue.length - volumeIndex - 1;
      }
      final volume = detail.catalogue[volumeIndex];
      final volumeCids = volume.chapters.map((c) => c.cid).toList();

      // StreamBuilder 实时监听阅读历史变化
      return StreamBuilder(
        stream: DBService.instance.getWatchableReadHistoryByVolume(volumeCids),
        builder: (context, volumeSnapshot) => Obx(() {
          // 计算卷的多选状态（三态 checkbox）
          final selectedChaps = volume.chapters.where((c) => c.isSelected.value).length;
          final isPartiallySelected = selectedChaps > 0 && selectedChaps < totalChaps;
          final bool? volumeCheckboxValue =
            selectedChaps == totalChaps ? true : (isPartiallySelected ? null : false);

          // 计算卷的阅读进度
          final volumeSubtitle = controller.getReadHistoryProgressByVolume(
            volumeSnapshot.data ?? [], volume.chapters.length
          );

          return GestureDetector(
            onLongPress: () {
              // 长按卷 → 进入多选模式并选中该卷
              if (!controller.isSelectionMode.value) {
                controller.enterSelectionMode();
                controller.toggleVolumeSelection(volumeIndex);
              }
            },
            child: ExpansionTile(
              leading: controller.isSelectionMode.value
                ? Checkbox(tristate: true, value: volumeCheckboxValue, ...)
                : null,
              title: Text(volume.title),
              subtitle: Text(volumeSubtitle),  // "未读" / "部分已读" / "全部已读"
              children: volume.chapters.asMap().entries.map((entry) {
                final chapterIndex = entry.key;
                final chapter = entry.value;

                // 检测章节是否已缓存
                controller.checkIsChapterCached(chapter.cid);

                // StreamBuilder 实时监听单个章节的阅读历史
                return StreamBuilder(
                  stream: DBService.instance.getWatchableReadHistoryByCid(chapter.cid),
                  builder: (context, chapterSnapshot) {
                    return Obx(() {
                      final readHistory = chapterSnapshot.data;
                      // 已读完 → 字体变灰
                      final titleColor = readHistory?.progress == 100
                        ? disabledColor : onSurfaceColor;

                      // 构建副标题："上次阅读 • 50% • 已缓存"
                      var cacheString = cachedChapter.contains(chapter.cid) ? " • 已缓存" : "";
                      var lastReadString = readHistory?.isLatest == true ? "上次阅读 • " : "";

                      return ListTile(
                        leading: controller.isSelectionMode.value
                          ? Checkbox(value: chapter.isSelected.value, ...)
                          : null,
                        title: Text(chapter.title, color: titleColor),
                        subtitle: Text(lastReadString + progress + cacheString),
                        onTap: () async {
                          if (controller.isSelectionMode.value) {
                            controller.toggleChapterSelection(volumeIndex, chapterIndex);
                            return;
                          }
                          // 获取上次阅读位置
                          final history = await DBService.instance.getReadHistoryByCid(chapter.cid);
                          var location = 0;
                          // 检查阅读模式是否匹配
                          if (history?.readerMode matches currentDirection) {
                            location = history?.location ?? 0;
                          }
                          Get.toNamed(RoutePath.reader, parameters: {
                            "cid": chapter.cid,
                            "location": "$location"
                          });
                        },
                        onLongPress: () {
                          // 长按章节 → 进入多选
                          if (!controller.isSelectionMode.value) {
                            controller.enterSelectionMode();
                          }
                          controller.toggleChapterSelection(volumeIndex, chapterIndex);
                        },
                      );
                    });
                  },
                );
              }).toList(),
            ),
          );
        }),
      );
    }, childCount: detail.catalogue.length),
  );
}
```

**目录的两层 StreamBuilder：**
- 外层：`getWatchableReadHistoryByVolume(volumeCids)` → 监听整卷的阅读进度
- 内层：`getWatchableReadHistoryByCid(chapter.cid)` → 监听单章节的阅读进度

阅读进度变化时（比如从阅读器返回），目录自动刷新显示最新状态。

```dart
void toggleVolumeSelection(int volumeIndex) {

  final allSelected = volume.chapters.every((c) => c.isSelected.value);

  final volume = novelDetail.value!.catalogue[volumeIndex];
  final selected = volume.chapters.where((c) => c.isSelected.value).length;
  if (selected == 0) volume.isSelected.value = false;
  else if (selected == volume.chapters.length) volume.isSelected.value = true;
  // 部分选中：volume.isSelected 保持 false，UI 用 tristate 显示半选
}
```

### 3.10 书架操作

```dart
// 添加到书架
void addToBookshelf() async {
  if (_isAdding) return;          // 防抖
  if (!_checkLogin()) return;     // 检查登录
  _isAdding = true;

  final result = await Api.addNovel(aid: aid);
  switch (result) {
    case Success():
      if (Parser.isError(result.data)) {
        // 添加失败（可能已满）
        Get.dialog(AlertDialog(content: "add_to_bookshelf_failed_tip"));
        isInBookshelf.value = false;
      } else {
        await bookshelfController.refreshDefaultBookshelf();  // 刷新默认书架
        isInBookshelf.value = true;
      }
    case Error():
      showErrorDialog(result.error);
  }
  _isAdding = false;
}

// 从书架移除
void removeFromBookshelf() async {
  if (_isRemoving) return;        // 防抖
  if (!_checkLogin()) return;
  _isRemoving = true;

  final bs = await DBService.instance.getAllBookshelf();
  final delId = bs.firstWhere((i) => i.aid == aid).bid;  // 获取书架条目 bid
  final result = await Api.removeNovel(delid: delId);
  switch (result) {
    case Success():
      isInBookshelf.value = false;
    case Error():
      showErrorDialog(result.error);
  }
  _isRemoving = false;
}
```

**isValidReadHistory() — 检查阅读记录是否适用于当前设置：**

```dart
bool isValidReadHistory(ReadHistoryEntityData? data) {
  if (data == null) return false;
  // 检查双页模式是否一致
  bool isDualPage = switch (LocalStorageService.instance.getReaderDualPageMode()) {
    DualPageMode.auto => context.shouldAutoUseDualPage(),
    DualPageMode.enabled => true,
    DualPageMode.disabled => false,
  };
  // 检查阅读方向是否一致（滚动 vs 翻页）
  bool isSameReaderMode = switch (LocalStorageService.instance.getReaderDirection()) {
    ReaderDirection.leftToRight => data.readerMode == kPageReadMode,
    ReaderDirection.rightToLeft => data.readerMode == kPageReadMode,
    ReaderDirection.upToDown => data.readerMode == kScrollReadMode,
  };
  return data.isDualPage == isDualPage && isSameReaderMode;
}
```

如果用户切换了阅读模式（比如从滚动改为翻页），之前的阅读位置记录就不适用了，FAB 不会显示。

## 六、总结

### 6.1 两个页面的核心职责

**BookshelfPage** 是用户的收藏管理中心：
- 6 个分类 TabBar 管理不同书架分组
- 多选模式支持批量移动和删除
- 搜索模式支持本地模糊搜索
- 数据来源：wenku8 API → 本地数据库 → UI（通过 `listen()` 实时同步）

**NovelDetailPage** 是单本小说的完整操作入口：
- 展示小说信息（模糊背景封面、简介、标签、热度）
- 目录列表实时显示阅读进度和缓存状态
- 多选模式支持批量缓存章节、标记已读/未读
- 继续阅读 FAB 自动定位到上次阅读位置
- 收藏/取消收藏操作与书架页面联动

### 6.2 数据流总览

```
wenku8 API ──→ Parser 解析 ──→ Controller 状态 ──→ Obx/StreamBuilder ──→ UI
                                  │
                                  ├──→ 本地数据库（持久化）
                                  │     ├─ 书架数据
                                  │     ├─ 浏览历史
                                  │     ├─ 阅读进度
                                  │     └─ 小说详情缓存
                                  │
                                  └──→ 缓存文件系统
                                        └─ cached_chapter/{aid}_{cid}.txt
```

两个页面的数据都经过：**网络请求 → HTML 解析 → Controller 状态管理 → UI 响应式渲染**。持久化数据通过 `listen()`/`StreamBuilder` 实现自动同步。

### 6.3 关键设计模式

| 模式 | 应用场景 | 效果 |
|------|---------|------|
| 数据库 `listen()` + StreamBuilder | 书架列表、目录阅读进度 | 数据变化时 UI 自动刷新，无需手动 setState |
| `RxBool isSelected` 多选状态 | 书架封面、卷、章节 | 响应式多选，UI 自动切换选中样式 |
| 三态 Checkbox | 卷级别多选 | 全选/半选/未选三种状态 |
| `_isClosed` 生命周期保护 | 网络请求回调 | Controller 销毁后不再更新状态，防止崩溃 |
| `_isAdding`/`_isRemoving` 防抖 | 收藏/取消收藏按钮 | 防止快速点击重复调用 API |
| 离线缓存回退 | 小说详情加载 | 网络失败时自动从本地数据库恢复 |
| 阅读模式校验 | 继续阅读 FAB | 切换阅读模式后旧位置记录不生效 |
| `GetxService` | 缓存队列控制器 | 跨页面共享，不会被自动销毁 |
| 并发控制循环 | 章节下载队列 | 限制同时下载数量，支持暂停/取消 |
| `KeepAliveWrapper` | 书架分类页面 | 切换 Tab 不销毁已加载的页面 |
| `showBookshelfBottomActionBar` | 书架多选模式 | 书架操作栏替换主导航栏，不占用书架页面空间 |
| Blur + 渐变遮罩 | 小说详情封面 | 三层叠加实现模糊背景效果 |

### 6.4 两个页面的关联

```
BookshelfPage                              NovelDetailPage
─────────────                              ───────────────
refreshBookshelf() ──→ API + 数据库          addToBookshelf() ──→ refreshDefaultBookshelf()
                                             removeFromBookshelf() ──→ API
多选删除 ──→ Api.removeNovelFromList()        书架检查 ──→ getAllBookshelf() → isInBookshelf
多选移动 ──→ Api.moveNovelToOther()

     两者通过 BookshelfController 共享书架状态
     NovelDetailPage 的收藏操作会触发 BookshelfPage 的数据刷新
```

### 6.5 防御性编程清单

这个两个页面集中体现了项目的防御性编程实践：

1. **`_isClosed`** — Controller 销毁后网络回调不再更新状态
2. **`_isFabVisible`** — FAB 动画状态与实际可见性同步
3. **`_isAdding`/`_isRemoving`/`_isNavigating`** — 防止快速点击重复操作
4. **`isValidReadHistory()`** — 阅读记录与当前设置不匹配时不使用
5. **`Parser.isError()`** — 每次网络请求后检查是否返回错误页
6. **`_getNovelDetailByLocal()`** — 网络失败时回退到本地缓存
7. **`ExcludeSemantics`** — 防止 Windows 无障碍模块崩溃（第 08 章）
8. **`PopScope` 返回键优先级** — 多选退出 > 搜索退出 > 导航 pop
