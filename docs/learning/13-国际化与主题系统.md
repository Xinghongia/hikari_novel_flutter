# 13 - 国际化与主题系统

app_translations.dart 提供简体中文和繁体中文两套完整的 UI 文本翻译，覆盖小说分类、阅读设置、网络错误提示等所有界面文案，通过 GetX 的 .tr 扩展方法引用。main.dart 中的主题系统根据平台分发：Android 端使用 DynamicColorBuilder 尝试系统动态取色，其他平台使用品牌色生成亮色/暗色 ColorScheme，所有平台均启用 Material 3 设计。

---

## 一、国际化（i18n）

### 1.1 翻译文件结构

```dart
// lib/common/app_translations.dart
class AppTranslations extends Translations {
  @override
  Map<String, Map<String, String>> get keys => {
    "zh_CN": { ... },  // 简体中文，约 200 条
    "zh_TW": { ... },  // 繁体中文，约 200 条
  };
}
```

两套翻译完全对应，覆盖所有界面文案。

### 1.2 翻译分类

| 分类 | 示例 key | zh_CN | zh_TW |
|------|---------|-------|-------|
| 导航标签 | `home` | 首页 | 首頁 |
| 小说分类（40+） | `school` | 校园 | 校園 |
| 排行榜类型（14） | `all_visit` | 总排行 | 總排行 |
| 排序方式（4） | `sort_by_update` | 按更新查看 | 依更新查看 |
| 阅读设置 | `font_size` | 字体大小 | 字體大小 |
| 缓存状态（6） | `downloading` | 下载中 | 下載中 |
| 网络错误 | `cloudflare_challenge_exception_tip` | Cloudflare 拦截提示... | ... |
| TTS 设置 | `speech_rate` | 语速 | 語速 |
| 操作反馈 | `send_successfully` | 发表成功 | 發表成功 |
| 通用 UI | `save` / `cancel` | 保存 / 取消 | 儲存 / 取消 |

### 1.5 语言切换

```dart
// lib/pages/setting/controller.dart
void changeLanguage(Language l) async {
  switch (l) {
    case Language.simplifiedChinese:
      Get.updateLocale(Locale("zh", "CN"));
    case Language.traditionalChinese:
      Get.updateLocale(Locale("zh", "TW"));
    case Language.followSystem:
      if (Get.deviceLocale == Locale("zh", "CN") || Get.deviceLocale == Locale("zh", "TW")) {
        Get.updateLocale(Get.deviceLocale!);
      } else {
        Get.updateLocale(Locale("zh", "CN"));  // 非中文系统默认简体
      }
  }
  language.value = l;
  LocalStorageService.instance.setLanguage(l);
}
```

**`Get.updateLocale()`** 会触发整个应用重建，所有 `.tr` 引用自动切换到新语言。

### 1.6 初始化时的语言检测

```dart
// lib/common/util.dart
static Locale getCurrentLocale() {
  final language = LocalStorageService.instance.getLanguage();
  if (language == Language.followSystem) {
    if (Get.deviceLocale == Locale("zh", "CN")) return Locale("zh", "CN");
    if (Get.deviceLocale == Locale("zh", "TW")) return Locale("zh", "TW");
    return Locale("zh", "CN");  // 非中文系统默认简体
  }
  return switch (language) {
    Language.simplifiedChinese => Locale("zh", "CN"),
    Language.traditionalChinese => Locale("zh", "TW"),
    _ => Locale("zh", "CN"),
  };
}
```

## 二、主题系统

### 2.1 架构概览

```
main.dart
  │
  ├─ 读取设置：brandColor、currentThemeValue、isDynamicColor
  │
  ├─ Platform.isAndroid?
  │    ├─ true  → AndroidApp（DynamicColorBuilder）
  │    └─ false → OtherApp（品牌色直接生成）
  │
  └─ BuildMainApp（统一构建 GetMaterialApp）
       ├─ theme: ThemeData(colorScheme: lightColorScheme, useMaterial3: true)
       └─ darkTheme: ThemeData(colorScheme: darkColorScheme, useMaterial3: true)
```

### 2.2 Android 端：动态取色

```dart
class AndroidApp extends StatelessWidget {
  Widget build(BuildContext context) {
    return DynamicColorBuilder(
      builder: ((ColorScheme? lightDynamic, ColorScheme? darkDynamic) {
        ColorScheme? lightColorScheme;
        ColorScheme? darkColorScheme;

        if (lightDynamic != null && darkDynamic != null && isDynamicColor) {
          // ✅ 动态取色成功（Android 12+ Material You）
          lightColorScheme = lightDynamic.harmonized();
          darkColorScheme = darkDynamic.harmonized();
        } else {
          // ❌ 动态取色失败（旧版 Android 或用户关闭）→ 回退到品牌色
          lightColorScheme = ColorScheme.fromSeed(seedColor: brandColor, brightness: Brightness.light);
          darkColorScheme = ColorScheme.fromSeed(seedColor: brandColor, brightness: Brightness.dark);
        }

        return BuildMainApp(lightColorScheme: lightColorScheme, darkColorScheme: darkColorScheme, ...);
      }),
    );
  }
}
```

**`DynamicColorBuilder`** 是 `dynamic_color` 包提供的 widget，它监听系统壁纸颜色，生成 `ColorScheme`。`harmonized()` 方法让颜色与应用品牌色协调。

### 2.3 其他平台：品牌色生成

```dart
class OtherApp extends StatelessWidget {
  Widget build(BuildContext context) {
    return BuildMainApp(
      lightColorScheme: ColorScheme.fromSeed(seedColor: brandColor, brightness: Brightness.light),
      darkColorScheme: ColorScheme.fromSeed(seedColor: brandColor, brightness: Brightness.dark),
      currentThemeValue: currentThemeValue,
    );
  }
}
```

**`ColorScheme.fromSeed()`** 是 Material 3 的种子色生成算法，从一个种子色自动推导出完整的亮色/暗色配色方案。

### 2.4 统一构建入口

```dart
class BuildMainApp extends StatelessWidget {
  Widget build(BuildContext context) {
    return GetMaterialApp(
      theme: ThemeData(
        useMaterial3: true,
        colorScheme: currentThemeValue == ThemeMode.dark ? darkColorScheme : lightColorScheme,
        snackBarTheme: snackBarTheme,  // 自定义 SnackBar 样式
        pageTransitionsTheme: PageTransitionsTheme(
          builders: {TargetPlatform.android: ZoomPageTransitionsBuilder(allowEnterRouteSnapshotting: false)},
        ),
        fontFamily: Platform.isWindows ? "Microsoft YaHei" : null,
      ),
      darkTheme: ThemeData(
        useMaterial3: true,
        colorScheme: currentThemeValue == ThemeMode.light ? lightColorScheme : darkColorScheme,
      ),
      ...
    );
  }
}
```

**关键细节：** `theme` 和 `darkTheme` 的 `colorScheme` 选择逻辑：

| currentThemeValue | theme 的 colorScheme | darkTheme 的 colorScheme |
|-------------------|---------------------|-------------------------|
| `ThemeMode.light` | lightColorScheme | lightColorScheme（强制） |
| `ThemeMode.dark` | darkColorScheme（强制） | darkColorScheme |
| `ThemeMode.system` | lightColorScheme | darkColorScheme |

这样当用户手动选择浅色/深色时，不会被系统的深浅模式覆盖。

### 2.5 主题设置项

```dart
// lib/pages/setting/controller.dart
class SettingController extends GetxController {
  Rx<ThemeMode> themeMode = Rx(LocalStorageService.instance.getThemeMode());
  RxBool isDynamicColor = LocalStorageService.instance.getIsDynamicColor().obs;
  Rx<Color> customColor = Rx(LocalStorageService.instance.getCustomColor());

  void changeThemeMode(ThemeMode mode) {
    themeMode.value = mode;
    LocalStorageService.instance.setThemeMode(mode);
    Get.forceAppUpdate();  // 强制重建整个应用
  }

  void changeIsDynamicColor(bool enabled) {
    isDynamicColor.value = enabled;
    LocalStorageService.instance.setIsDynamicColor(enabled);
    Get.forceAppUpdate();  // 强制重建整个应用
  }

  void changeCustomColor(Color color) {
    customColor.value = color;
    LocalStorageService.instance.setCustomColor(color);
    Get.forceAppUpdate();  // 强制重建整个应用
  }
}
```

**`Get.forceAppUpdate()`** 强制重建 `GetMaterialApp`，让新的主题设置生效。

**动态取色与自定义色的互斥逻辑：**
- Android + 动态取色开启 → 隐藏自定义颜色选择器
- 其他平台或动态取色关闭 → 显示自定义颜色选择器

## 三、总结

### 3.1 国际化架构

```
AppTranslations (keys)
  ├─ zh_CN: { "home": "首页", ... }  // 简体中文
  └─ zh_TW: { "home": "首頁", ... }  // 繁体中文

引用方式："home".tr

切换方式：Get.updateLocale(Locale("zh", "TW"))
  → 触发应用重建 → 所有 .tr 引用自动更新

参数替换："bookshelf_number_selection".trParams({"no": "2"})
  → "第 2 书架"
```

### 3.2 主题架构

```
设置存储（LocalStorageService / Hive）
  ├─ themeMode: ThemeMode.system / light / dark
  ├─ isDynamicColor: bool
  └─ customColor: Color

main.dart 读取设置
  │
  ├─ Android → DynamicColorBuilder
  │    ├─ 动态取色成功 → harmonized()
  │    └─ 失败或关闭 → ColorScheme.fromSeed(brandColor)
  │
  └─ 其他平台 → ColorScheme.fromSeed(brandColor)
       │
       ▼
  BuildMainApp
    ├─ theme: ThemeData(useMaterial3: true, colorScheme: light/dark)
    └─ darkTheme: ThemeData(useMaterial3: true, colorScheme: light/dark)

用户修改设置 → Get.forceAppUpdate() → 整个应用重建
```

### 3.3 关键设计

| 设计 | 效果 |
|------|------|
| GetX `.tr` 国际化 | 零样板代码，任何字符串直接 `.tr` 即可翻译 |
| `Get.updateLocale()` | 语言切换时自动重建整个应用 |
| `DynamicColorBuilder` | Android 12+ 自动跟随壁纸取色 |
| `ColorScheme.fromSeed()` | Material 3 种子色算法，一个颜色推导整套配色 |
| `Get.forceAppUpdate()` | 主题/颜色变更后强制重建 |
| `theme` vs `darkTheme` 交叉赋值 | 手动选择深浅色时不被系统深浅模式覆盖 |
| 深浅模式分离存储 | 阅读器的文字颜色/背景颜色/背景图片分别存 day/night 两套 |
| `fallbackLocale` | 翻译缺失时回退到简体中文 |
| EasyRefresh 国际化 | 刷新/加载提示文字也跟随语言切换 |
