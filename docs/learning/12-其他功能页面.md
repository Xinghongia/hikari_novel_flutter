# 12 - 其他功能页面

除核心流程外，应用还包含多个辅助页面：搜索页面支持小说搜索和历史记录，分类页面提供 40+ 标签筛选和 4 种排序方式，排行榜页面展示不同类型的小说排名，评论和回复页面实现社区互动，登录页面通过 InAppWebView 嵌入 wenku8 网站完成认证，缓存队列页面管理章节下载任务的并发调度。这些页面共享基类控制器的分页加载和状态管理模式。

## 一、SearchPage — 搜索页

搜索页是唯一**没有继承基类**的分页页面，因为它的分页逻辑有特殊处理（搜索结果可能只有一条时直接跳转详情）。

### 1.1 结构

```
SearchPage
  └─ NestedScrollView
       ├─ SliverAppBar（可折叠）
       │    └─ FlexibleSpaceBar
       │         ├─ 搜索输入框（TextField）
       │         ├─ 搜索模式（按标题 / 按作者 ChoiceChip）
       │         └─ 搜索历史（横向滚动 ActionChip 列表 + 清除按钮）
       │
       └─ body: Stack
            ├─ success → EasyRefresh + ResponsiveGridList
            ├─ loading → CircularProgressIndicator
            ├─ empty → "搜索内容为空"
            ├─ error → 错误信息
            ├─ jumpToOtherPage → "已跳转到其他页面"
            ├─ inFiveSecond → "搜索太快了"
            └─ needLogin → 登录提示
```

### 1.2 搜索流程

```
用户输入关键词 → 回车
  │
  ▼
controller.getPage(false)
  │  ① 保存搜索历史到数据库
  │     DBService.upsertSearchHistory(keyword)
  │  ② 根据 searchMode 选择 API
  │     searchMode == 0 → Api.searchNovelByTitle(title, index)
  │     searchMode == 1 → Api.searchNovelByAuthor(author, index)
  │
  ▼
处理结果
  │  ① Parser.isError() → 需要登录
  │  ② Parser.isSearchResultOnlyOne(html)
  │     → 如果只有一条结果，直接返回 NovelCover（不走分页）
  │  ③ Parser.parseToList(html) → 解析小说列表
  │  ④ 空结果 → pageState = empty
  │
  ▼
UI 刷新
```

### 1.3 特殊状态

| 状态 | 含义 |
|------|------|
| `pleaseSelect` | 初始状态，等待用户输入 |
| `jumpToOtherPage` | 搜索结果只有一条，自动跳转详情 |
| `inFiveSecond` | 5 秒内重复搜索，限制频率 |

### 1.4 搜索历史

```dart
// 实时监听数据库变化
DBService.instance.getAllSearchHistory().listen((sh) =>
  searchHistory.assignAll(sh.reversed.map((e) => e.keyword))
);

// 从历史搜索
void searchFromHistory(String keyword) {
  keywordController.text = keyword;
  keywordController.selection = TextSelection.fromPosition(
    TextPosition(offset: keywordController.text.length)  // 光标移到末尾
  );
  getPage(false);
  Get.focusScope?.unfocus();  // 收起键盘
}
```

### 1.5 作者搜索入口

从小说详情页点击作者名时，会带 `author` 参数进入搜索页：

```dart
// NovelDetailPage
GestureDetector(
  onTap: () => AppSubRouter.toSearch(author: detail.author),
  child: IconText(icon: person, text: detail.author),

// SearchController
void checkIsAuthorSearch(String? author) {

    searchMode.value = 1;  // 自动切换到按作者搜索
    getPage(false);         // 自动触发搜索
  }
```

```dart
class CategoryController extends BaseSelectListPageController<NovelCover> {
  RxString category = "please_select".tr.obs;
  RxString sortText = "please_select".tr.obs;
  String sortValue = "";

  @override
  void onInit() {
    super.onInit();
    // 两个条件都选好后自动触发刷新
    everAll([category, sortText], (_) {

        easyRefreshController.callRefresh(force: true);

    });
  }
}
```

## 六、LoginPage — 登录页

通过 InAppWebView 嵌入 wenku8 网站完成认证。

### 6.1 登录流程

```
LoginPage
  │  渲染 InAppWebView，加载 wenku8/login.php
  │
  ▼
用户在 WebView 中输入账号密码 → 登录
  │
  ▼
WebView 跳转到 wenku8 首页
  │
  ▼
LoginController.saveCookie(WebUri uri)
  │  ① 检测 URL 是否包含 "wenku8"
  │  ② 获取 WebView Cookie
  │  ③ 检查是否包含 "jieqiUserInfo" 和 "jieqiVisitInfo"
  │  ④ 拼接 Cookie 字符串
  │  ⑤ LocalStorageService.setCookie(cookie)
  │  ⑥ Request.initCookie()
  │  ⑦ _getUserInfo() — 获取用户信息
  │  ⑧ _refreshBookshelf() — 刷新全部 6 个书架分类
  │
  ▼
Get.offAllNamed(RoutePath.main)  // 清空导航栈，跳转主页
```

### 6.2 关键代码

```dart
class LoginController extends GetxController {
  final CookieManager cookieManager = CookieManager.instance();
  InAppWebViewController? inAppWebViewController;

  @override
  void onInit() {
    super.onInit();
    cookieManager.deleteAllCookies();  // 清除旧 Cookie
  }

  Future<void> saveCookie(WebUri uri) async {
    if (uri.toString().contains("wenku8")) {
      final getCookie = await cookieManager.getCookies(url: uri);

      // 检查必需的 Cookie
      bool hasCookie = ["jieqiUserInfo", "jieqiVisitInfo"].every(
        (keyword) => getCookie.any((c) => c.name.contains(keyword)),
      );

      if (hasCookie) {
        // 存储 Cookie
        String cookie = "jieqiUserInfo=${...};jieqiVisitInfo=${...}";
        LocalStorageService.instance.setCookie(cookie);
        Request.initCookie();

        // 获取用户信息 + 刷新书架
        try {
          await _getUserInfo();
          await _refreshBookshelf();
        } catch (e) {
          // 失败时清除 Cookie
          LocalStorageService.instance.setCookie(null);
          Request.deleteCookie();
          pageState.value = PageState.error;
          return;
        }

        Get.offAllNamed(RoutePath.main);  // 登录成功
      }
    }
  }
}
```

## 七、CacheQueuePage — 缓存队列页

已在第 10 章详述，此处补充并发调度机制。

### 7.1 并发控制

```dart
class CacheQueueController extends GetxService {
  final int concurrency = 1;  // 默认单线程下载

  Future<void> _processLoop() async {
    while (_isProcessing) {
      // 并发数已满 → 等待
      if (_running.length >= concurrency) {
        await Future.delayed(300ms);
        continue;
      }

      // 找到下一个 pending 任务
      final next = tasks.where((t) => t.status == CacheStatus.pending);
      if (next.isEmpty) {
        _isProcessing = false;  // 无任务，停止循环
        break;
      }

      // 启动下载
      final task = next.first;
      task.status = CacheStatus.downloading;
      tasks.refresh();

      final future = _runTask(task).whenComplete(() => _running.remove(task.uuid));
      _running[task.uuid] = future;

      await Future.delayed(100ms);  // 短暂让出，评估并发
    }
  }
}
```

### 7.2 状态机

```
pending → downloading → completed（成功后从列表移除）
                     → failed（可重试）
                     → canceled（可重试）
pending → paused（暂停后可恢复）
```

## 八、总结

### 8.1 各页面对比

| 页面 | 基类 | 数据类型 | 加载方式 | 特殊功能 |
|------|------|---------|---------|---------|
| Search | 无（手动实现） | NovelCover | 用户输入触发 | 搜索历史、单结果跳转、作者搜索 |
| Category | BaseSelectListPageController | NovelCover | 条件选择后触发 | 40+ 标签、4 种排序 |
| Ranking | BaseSelectListPageController | NovelCover | 条件选择后触发 | 14 种排行榜 |
| Comment | BaseListPageController | CommentItem | 自动加载 | 发送评论、FAB 动画 |
| Reply | BaseListPageController | ReplyItem | 自动加载 | 发送回复、FAB 动画 |
| Login | 无 | - | - | InAppWebView、Cookie 认证 |
| CacheQueue | GetxService | ChapterCacheTask | - | 并发控制、暂停/取消/重试 |

### 8.2 共享模式

所有页面（除 Login 和 CacheQueue）共享以下模式：

1. **PageState 状态机**：loading → success / error / empty / needLogin
2. **Offstage + Obx**：响应式切换 UI 状态
3. **登录拦截**：`Parser.isError()` → `pageState = needLogin` → 显示登录提示
4. **分页引擎**：`_index` 递增 + `_maxNum` 限制 + `IndicatorResult` 反馈
5. **防抖**：操作栏显隐、收藏/取消收藏、导航跳转
