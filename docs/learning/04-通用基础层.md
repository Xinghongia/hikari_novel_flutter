# 第四章 通用基础层：工具、常量与扩展

> common 目录是跨页面复用的基础设施层，构成了整个应用的公共语言。

## 概述

| 层级     | 文件                        | 职责                 |

## 1. constants.dart — 全局常量

```dart
const String kAppName = "Hikari Novel";
const int kStatusBarPadding = 30;
const double kSmallIconSize = 16.0;
const double kCardBorderRadius = 6.0;
const EdgeInsets kCommentAndReplyCardPadding = EdgeInsets.fromLTRB(20, 16, 20, 16);
const int kScrollReadMode = 1;
const int kPageReadMode = 2;
```

命名规范统一使用 `k` 前缀（Dart 常量命名约定），涵盖 3 类常量：

| 类别       | 常量                | 用途                     |
| ---------- | ------------------- | ------------------------ |
| 应用信息   | kAppName            | 应用名称                 |
| UI 尺寸    | kStatusBarPadding, kSmallIconSize, kCardBorderRadius | 状态栏/图标/卡片圆角 |
| 文本样式   | kBaseTileTitleTextStyle, kBaseTileSubtitleTextStyle, kCommentAndReplyUsernameTextStyle | 标题/副标题/评论用户名 |
| 阅读模式   | kScrollReadMode, kPageReadMode | 滚动阅读/翻页阅读   |

注意：`TextStyle` 常量使用 `final` 而非 `const`，因为 `TextStyle` 构造函数依赖运行时主题色（如 `kCommentAndReplyUsernameTextStyle` 引用了 `Theme.of(Get.context!).colorScheme.primary`）。

## 2. extension.dart — 扩展方法

三个扩展分别增强 GetX、BuildContext 和 String 的能力。

### 2.1 GetInterface 扩展：懒加载依赖注入

```dart
extension Controller on GetInterface {
  T findOrPut<T>(T Function() creator) {
    try {
      return Get.find<T>();
    } catch (_) {
      final instance = creator();
      Get.put<T>(instance);
      return instance;
    }
  }
}
```

**设计意图**：GetX 原生的 `Get.put()` 会重复注册，`Get.find()` 找不到会抛异常。`findOrPut` 实现了"先查找后创建"的懒加载模式——如果 Controller 已注册则直接返回，否则创建并注册。

**使用场景**：在需要跨页面共享 Controller 但不确定是否已注册时使用。

### 2.2 BuildContext 扩展：屏幕尺寸判断

```dart
extension ScreenInfo on BuildContext {
  bool isLargeScreen() => MediaQuery.of(this).size.width > MediaQuery.of(this).size.height;
  bool isTabletLikeScreen() => MediaQuery.of(this).size.shortestSide >= 600;
  bool shouldAutoUseDualPage() {
    final size = MediaQuery.of(this).size;
    return size.shortestSide >= 600 && size.width > size.height;
  }
}
```

三个方法的判断逻辑：

| 方法                | 条件                              | 用途           |
| ------------------- | --------------------------------- | -------------- |
| isLargeScreen       | 宽 > 高                           | 横屏判断       |
| isTabletLikeScreen  | 最短边 ≥ 600dp                    | 平板判断       |
| shouldAutoUseDualPage | 最短边 ≥ 600dp 且 宽 > 高        | 自动双页模式   |

**使用场景**：`MainPage` 根据 `shouldAutoUseDualPage()` 决定使用 `NavigationRail + 双栏布局` 还是 `BottomNavigationBar + 单栏布局`。

### 2.3 String 扩展：GBK/Big5 URL 编码

```dart
extension UrlEncodingIfNotAscii on String {
  String gbkUrlEncodingIfNotAscii() {
    final bytes = GbkCodec().encode(this);
    return _encode(bytes);
  }

  String big5UrlEncodingIfNotAscii() {
    final bytes = Big5Codec().encode(this);
    return _encode(bytes);
  }

  String _encode(List<int> bytes) {
    final buffer = StringBuffer();
    for (final byte in bytes) {
      if (byte >= 0x00 && byte <= 0x7F) {
        buffer.write(String.fromCharCode(byte));
      } else {
        buffer.write('%${byte.toRadixString(16).toUpperCase().padLeft(2, '0')}');
      }
    }
    return buffer.toString();
  }
}
```

**设计意图**：wenku8 的搜索接口使用 GBK/Big5 编码，而 Dart/Flutter 原生只支持 UTF-8。这两个扩展方法将中文字符串先编码为 GBK/Big5 字节流，再对非 ASCII 字节进行 `%XX` URL 编码。

**编码流程**：
```
"搜索词" → GbkCodec().encode() → [0xCB, 0xD1, 0xCB, 0xF7, 0xB4, 0xCA]
         → _encode() → "%CB%D1%CB%F7%B4%CA"
```

**使用位置**：`Api.getSearchNovel()` 和 `Api.getSearchAuthor()` 中对搜索关键词编码。

## 3. util.dart — 通用工具

### 3.1 日期格式化

```dart
static String getDateTime(String dateStr) {
  if (!LocalStorageService.instance.getIsRelativeTime()) {
    return dateStr;
  }
  final DateTime inputDate = DateTime.parse(dateStr);
  return Jiffy.parse(inputDate.toString()).fromNow();
}
```

根据用户设置决定显示"相对时间"（如"3天前"）还是原始日期字符串。使用 `Jiffy` 库的 `fromNow()` 方法。

### 3.2 语言/地区判断

```dart
static Locale getCurrentLocale() {
  final language = LocalStorageService.instance.getLanguage();
  if (language == Language.followSystem) {
    if (Get.deviceLocale == Locale("zh", "CN")) {
      return Locale("zh", "CN");
    } else if (Get.deviceLocale == Locale("zh", "TW")) {
      return Locale("zh", "TW");
    } else {
      return Locale("zh", "CN"); // 默认简体中文
    }
  }
  return switch (language) {
    Language.simplifiedChinese => Locale("zh", "CN"),
    Language.traditionalChinese => Locale("zh", "TW"),
    _ => Locale("zh", "CN"),
  };
}
```

三级优先级：用户手动设置 > 系统语言 > 默认简体中文。不支持英文等其他语言（wenku8 是中文轻小说网站）。

### 3.3 版本更新检查

```dart
static Future<void> checkUpdate(bool mustNotification) async {
  final response = await Api.fetchLatestRelease();
  // ...
  final remoteVer = data["tag_name"];
  final localVer = info.version;
  bool hasNewVersion = localVer != remoteVer.substring(0, remoteVer.indexOf("+"));
  // ...
}
```

通过 GitHub API 获取最新 Release 版本号，与本地 `PackageInfo.version` 比较。`mustNotification` 为 `true` 时即使已是最新也弹窗提示（用于手动检查更新）。

版本号比较逻辑：远程版本号去掉 `+N` 后缀后与本地版本号比较。

## 4. log.dart — 日志封装

```dart
class Log {
  static final Logger _logger = Logger(
    printer: PrefixPrinter(
      PrettyPrinter(methodCount: 3, dateTimeFormat: DateTimeFormat.dateAndTime)
    ),
  );

  static void t(dynamic message) => _logger.t(message);  // Trace
  static void d(dynamic message) => _logger.d(message);  // Debug
  static void i(dynamic message) => _logger.i(message);  // Info
  static void w(dynamic message) => _logger.w(message);  // Warning
  static void e(dynamic message) => _logger.e(message);  // Error
  static void f(dynamic message) => _logger.f(message);  // Fatal
}
```

封装 `logger` 库，提供 6 个日志级别。使用 `PrefixPrinter` 为每条日志添加级别前缀（如 `[D]`、`[E]`），`PrettyPrinter` 格式化堆栈信息和时间戳。

## 5. html_debug_logger.dart — HTML 调试日志

开发者模式专用工具，用于调试 HTML 解析问题。

```dart
class HtmlDebugLogger {
  static bool get _enabled => DevModeService.instance.enabled.value;

  static Future<void> log({required String scene, String? url, ...}) async { ... }
  static Future<void> dumpHtml({required String scene, required String html, ...}) async { ... }
}
```

| 方法      | 功能                       | 输出位置                      |
| --------- | -------------------------- | ----------------------------- |
| log       | 记录场景、URL、HTML 预览   | `html_debug.txt`              |
| dumpHtml  | 完整保存 HTML 文件 + 元数据 | `html_dumps/html_dump_*.html` |

**安全限制**：仅在 `DevModeService.instance.enabled` 为 `true` 时生效。Android 优先写入外部存储，其他平台写入应用文档目录。HTML 内容截断上限 2MB。

## 7. app_translations.dart — 国际化

使用 GetX 的 `Translations` 机制，支持两种语言：

| 语言   | Locale  | 代码标识 |
| ------ | ------- | -------- |
| 简体中文 | zh_CN | 主要语言 |
| 繁体中文 | zh_TW | 次要语言 |

翻译 key 覆盖 200+ 个文本项，涵盖：
- 导航标签（home, bookshelf, my）
- 小说分类（school, love, fantasy 等 40+ 个标签）
- 阅读器设置（font_size, line_spacing, reading_direction 等）
- TTS 控制（tts_engine, speech_rate, volume 等）
- 错误提示（network_error, cloudflare_challenge_exception_tip 等）

使用方式：`"key".tr`（GetX 扩展），带参数：`"key".trParams({"no": "1"})`。

## 8. migration.dart — 数据库迁移

| 迁移版本 | 变更内容                                                      |
