# 02 - 应用入口与初始化

## 概述

main.dart 是整个 Flutter 应用的起点。它依次初始化四个核心服务（LocalStorage、DevMode、DB、TTS），配置 WebView 环境和系统 UI 沉浸模式，然后根据平台分发到不同的主题构建路径：Android 端支持 Dynamic Color 动态取色，其他平台使用品牌色方案。最终构建的 MaterialApp 配置了路由表和国际化，根据 Cookie 状态决定进入主页还是欢迎页。

## 启动流程

```
main()

  │     ├── openBox("loginInfo")                     ← Cookie
  │     └── openBox("reader")                        ← 阅读器全部设置

  │     ├── refreshEngines()                         ← 获取 Android 可用 TTS 引擎列表
  │     │     └── MultiTTS (org.nobody.multitts) 优先排序
  │     ├── applyEngine(savedEngine)                 ← 恢复上次使用的引擎
  │     └── applyVoice(savedVoice)                   ← 恢复上次使用的音色
  │
  ├── WebView 环境初始化                              ← ⑤
  │     ├── Windows: WebViewEnvironment.create()
  │     └── Android: setWebContentsDebuggingEnabled(kDebugMode)

  ├── _init()                                        ← ⑥ UI 配置
  │     ├── Android: SystemChrome.setEnabledSystemUIMode(edgeToEdge)
  │     │              状态栏/导航栏透明沉浸
  │     └── EasyRefresh.defaultHeaderBuilder/FooterBuilder
  │           └── 国际化文本（下拉刷新/上拉加载提示）
  │

  ├── Request.initCookie()                           ← ⑧ Cookie 恢复
```

## 四个核心服务

### LocalStorageService — 本地存储

基于 Hive 的键值存储，管理 3 个 box：

| Box | 存储内容 |
|-----|----------|
| `setting` | 主题模式、自定义颜色、动态取色、语言、节点、自动更新、UserInfo |
| `loginInfo` | Cookie |
| `reader` | 阅读方向、字体大小、行距、边距、双页模式、背景色/图、TTS 设置、首行缩进、段距等 |

所有设置项通过 getter/setter 方法访问，返回值都有默认值兜底。

```dart
// 使用示例
ThemeMode getThemeMode() => ThemeMode.values[
  _setting.get(kThemeMode, defaultValue: ThemeMode.system.index)
];
```

### DevModeService — 开发者模式

最简单的服务，只有一个 `RxBool enabled`：

```dart
class DevModeService extends GetxService {
  final RxBool enabled = false.obs;

  void init() => enabled.value = LocalStorageService.instance.getDevModeEnabled();

  bool toggle() {
    enabled.value = !enabled.value;
    LocalStorageService.instance.setDevModeEnabled(enabled.value);
    return enabled.value;
  }
}
```

开启后在"我的"页面显示开发者工具入口。

### DBService — 数据库服务

Drift ORM 的薄封装层，对外暴露 Stream（响应式）和 Future（一次性查询）：

| 表 | 用途 | 关键方法 |
|----|------|----------|
| BookshelfEntity | 书架收藏 | insertAllBookshelf / getBookshelfByClassId (Stream) |
| BrowsingHistoryEntity | 浏览历史 | upsertBrowsingHistory / getWatchableAllBrowsingHistory (Stream) |
| SearchHistoryEntity | 搜索历史 | upsertSearchHistory / getAllSearchHistory (Stream) |
| ReadHistoryEntity | 阅读进度 | upsertReadHistory / getLastestReadHistoryByAid (Stream) |
| NovelDetailEntity | 小说详情缓存 | upsertNovelDetail / getNovelDetail |

ReadHistory 的 upsert 用事务实现：先把同 aid 的旧记录 `isLatest` 设为 false，再插入新记录。

### TtsService — TTS 朗读服务

初始化最重的服务，涉及系统 TTS 引擎交互：

```
init()
  ├── awaitTts.setSpeechRate/Pitch/Volume         ← 应用用户保存的设置
  ├── _applyBestLanguage()                         ← 按优先级选择语言
  ├── refreshEngines()                             ← 获取 Android 引擎列表
  │     └── MultiTTS 优先，系统 TTS 其次
  ├── applyEngine(savedEngine)                     ← 恢复引擎
  ├── _applyBestLanguage()                         ← 再次应用语言（引擎切换后）
  └── refreshVoices() + applyVoice(savedVoice)     ← 恢复音色
```

TTS 支持两种播放模式：
- `speak(text)` — 单次播放
- `startChapter(fullText)` — 分段播放（按句号/感叹号/问号分句，每段最长 140 字）

## MyApp 构建

### 平台分发

```dart
MyApp
├── Platform.isAndroid ?
│   ├── Yes → AndroidApp
│   │     └── DynamicColorBuilder
│   │           ├── 系统取色成功 → harmonized() 配色
│   │           └── 取色失败 → ColorScheme.fromSeed(brandColor)
│   └── No  → OtherApp
│         └── ColorScheme.fromSeed(brandColor)
```

Android 端使用 `dynamic_color` 包实现 Material You 动态取色，其他平台（Windows/iOS/macOS/Linux）使用固定的种子色生成配色方案。

### GetMaterialApp 配置

```dart
GetMaterialApp(
  title: "Hikari Novel",
  theme: ThemeData(useMaterial3: true, colorScheme: ...),
  darkTheme: ThemeData(useMaterial3: true, colorScheme: ...),
  translations: AppTranslations(),        ← zh_CN + zh_TW 国际化
  locale: Util.getCurrentLocale(),        ← 跟随系统 or 用户选择
  getPages: AppRoutes.mainRoutePages,     ← 7 个主路由
  initialRoute: 有Cookie ? "/main" : "/welcome",
)
```

Windows 端强制使用 `Microsoft YaHei` 字体。

## 路由系统

### 主路由 vs 子路由

项目采用**双层路由**架构：

```
主路由（GetMaterialApp）
  /main      → MainPage（底部导航）
  /home      → HomePage
  /login     → LoginPage
  /photo     → PhotoPage
  /reader    → ReaderPage
  /welcome   → WelcomePage
  /reader_setting → ReaderSettingPage

子路由（Navigator id=1）
  /novel_detail   → NovelDetailPage
  /comment        → CommentPage
  /reply          → ReplyPage
  /user_bookshelf → UserBookshelfPage
  /browsing_history → BrowsingHistoryPage
  /user_info      → UserInfoPage
  /about          → AboutPage
  /setting        → SettingPage
  /search         → SearchPage
  /cache_queue    → CacheQueuePage
  /dev_tools      → DevToolsPage
  /logo           → LogoPage（空占位）
```

### 子路由机制

MainPage 内嵌一个独立的 Navigator（key = `AppSubRouter.subNavigatorKey`），通过 `onGenerateRoute` 分发子路由：

```dart
Navigator(
  key: AppSubRouter.subNavigatorKey,    ← Get.nestedKey(1)
  initialRoute: RoutePath.logo,         ← 初始显示空白占位
  onGenerateRoute: (settings) => AppRoutes.subRoutePages(settings),
)
```

`SubNavigatorObserver` 监听子路由的 push/pop 事件，控制内容区的显示/隐藏：

```dart
void didPush(Route route, Route? previousRoute) {
  AppSubRouter.currentContentRouteName = route.settings.name;
  Get.find<MainController>().showContent.value = routeName != RoutePath.logo;
}
```

### 大屏适配

MainPage 根据屏幕方向自适应布局：

```dart
context.isLargeScreen()   ← 宽度 > 高度
  ? _buildLargeScreenScaffold()   ← NavigationRail + 双栏
  : _buildSmallScreenScaffold()   ← NavigationBar + 单栏
```

大屏模式下，左侧 NavigationRail + 右侧双栏（内容列表 + 详情）。

## 首次启动流程

```
用户首次打开
  ↓
initialRoute = "/welcome"（无 Cookie）
  ↓
WelcomePage
  ├── 显示 Logo + 欢迎文字
  ├── "前往登录" 按钮
  └── 节点选择（www.wenku8.cc / www.wenku8.net）
      ↓ 用户选择节点后点击登录
Get.toNamed("/login")
  ↓
LoginPage
  ├── 加载 wenku8 登录页（WebView）
  ├── 用户在 WebView 中登录
  ├── saveCookie() 检测到 jieqiUserInfo + jieqiVisitInfo
  │     ├── LocalStorageService.setCookie()     ← 保存 Cookie
  │     ├── Request.initCookie()                ← 注入 Dio
  │     ├── Api.getUserInfo() + Parser.getUserInfo()  ← 获取用户信息
  │     └── Api.getBookshelf() × 6 个分类       ← 同步书架
  └── Get.offAllNamed("/main")                  ← 替换到主页
```

## 核心设计模式

| 模式 | 应用 | 说明 |
|------|------|------|
| GetX 全局服务 | 4 个 Service | `Get.put()` 注册，`Get.find()` 获取，生命周期跟随 App |
| GetX 响应式 | `.obs` + `Obx()` | 状态变化自动刷新 UI |
| 双层路由 | 主路由 + 子路由 | 主路由负责页面切换，子路由负责内容区导航 |
| Stream 响应式 | Drift `.watch()` | 数据库变化自动推送到 UI |
| 平台分支 | `Platform.isAndroid` | Android 特殊处理（动态取色、沉浸式、TTS 引擎） |
