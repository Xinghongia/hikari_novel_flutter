## 7.2 Request — HTTP 客户端封装

> 源码：`lib/network/request.dart`

### 7.2.1 Dio 实例配置

```dart
static final Dio dio = Dio(
  BaseOptions(
    headers: userAgent,
    responseType: ResponseType.bytes,    // 原始字节，方便 GBK 解码
    followRedirects: false,              // 手动处理 302 重定向
    validateStatus: (status) => status != null,  // 全部通过，交给拦截器处理
  ),
)
  ..interceptors.add(CloudflareInterceptor())
  ..interceptors.add(CookieManager(_dioCookieJar));
```

| 配置项 | 值 | 原因 |
|--------|-----|------|
| responseType | ResponseType.bytes | wenku8 使用 GBK/Big5 编码，需要原始字节才能解码 |
| followRedirects | false | wenku8 的 302 重定向需要手动处理（拼接域名） |
| validateStatus | 全部通过 | Cloudflare 的 403 不应抛异常，由拦截器判断 |

### 7.2.2 Cloudflare 拦截器

```dart
class CloudflareInterceptor extends Interceptor {
  @override
  void onResponse(Response<dynamic> response, ResponseInterceptorHandler handler) async {
    final statusCode = response.statusCode;

    // 403 → Cloudflare 封禁
    if (statusCode == 403) {
      handler.reject(Cloudflare403Exception(requestOptions: response.requestOptions));
      return;
    }

    // 检查 cf-mitigated header → Cloudflare 人机验证
    final cfMitigated = response.headers['cf-mitigated'];
    if (cfMitigated == null || !cfMitigated.contains('challenge')) {
      handler.next(response);  // 正常通过
      return;
    }

    // Cloudflare 人机验证
    handler.reject(CloudflareChallengeException(requestOptions: response.requestOptions));
  }
}
```

**两种 Cloudflare 异常**：

| 异常 | 触发条件 | 含义 |
|------|----------|------|
| Cloudflare403Exception | statusCode == 403 | IP 被 Cloudflare 封禁 |
| CloudflareChallengeException | cf-mitigated header 包含 "challenge" | 需要人机验证 |

### 7.2.3 Cookie 管理

```dart
static final _dioCookieJar = CookieJar();

static void initCookie() {
  final localCookie = LocalStorageService.instance.getCookie();  // 从 Hive 读取
  if (localCookie == null) return;

  // 解析 Cookie 字符串 → Cookie 对象列表
  final cookies = localCookie.split(';')
    .map((e) => e.trim())
    .where((e) => e.contains('='))
    .map((e) {
      final kv = e.split('=');
      return Cookie(kv[0], kv.sublist(1).join('='));
    }).toList();

  // 同时保存到两个节点
  _dioCookieJar.saveFromResponse(Uri.parse(Wenku8Node.wwwWenku8Cc.node), cookies);
  _dioCookieJar.saveFromResponse(Uri.parse(Wenku8Node.wwwWenku8Net.node), cookies);
}
```

**Cookie 初始化链路**：

```
main() → Request.initCookie()
  → LocalStorageService.getCookie()        // 从 Hive loginInfo Box 读取
  → 解析 "key1=val1; key2=val2" 字符串
  → 分割为 Cookie 对象列表
  → CookieJar.saveFromResponse() × 2      // 同时保存到 .cc 和 .net 两个节点
```

### 7.2.4 GET 请求链路

```dart
static Future<Resource> get(String url, {required CharsetsType charsetsType}) async {
  // 1. URL 拼接 charset 参数
  if (!url.contains("?")) url += "?";
  switch (charsetsType) {
    case CharsetsType.gbk: url += "&charset=gbk";
    case CharsetsType.big5Hkscs: url += "&charset=big5";
  }

  // 2. 发起请求（经过拦截器链）
  final response = await dio.get(url);

  // 3. 检查 302 重定向
  final result = await _checkRedirects(response);

  // 4. GBK/Big5 解码
  final raw = result as Uint8List;
  late String decodedHtml;
  switch (charsetsType) {
    case CharsetsType.gbk:
      decodedHtml = GbkDecoder().convert(raw);
    case CharsetsType.big5Hkscs:
      decodedHtml = Big5Decoder().convert(raw);
  }

  // 5. 返回结果
  return Success(decodedHtml);
}
```

**完整链路**：

```
Api.getNovelDetail(aid="1234")
  → url = "https://www.wenku8.cc/modules/article/articleinfo.php?id=1234"
  → Request.get(url, charsetsType: CharsetsType.gbk)
    → url += "&charset=gbk"
    → Dio.get(url)
      → CloudflareInterceptor.onResponse()
        → 检查 statusCode == 403 → reject(Cloudflare403Exception)
        → 检查 cf-mitigated header → reject(CloudflareChallengeException)
        → 正常 → next(response)
      → CookieManager.onRequest()
        → 从 CookieJar 附加 Cookie 到请求头
      → CookieManager.onResponse()
        → 从响应头保存 Cookie 到 CookieJar
      → HTTP 请求发送到 wenku8 服务器
      → 响应返回（bytes）
    → _checkRedirects(response)
      → statusCode 在 300-399？
        → 是 → 读取 Location header → 重新请求
        → 否 → 返回 response.data
    → GbkDecoder().convert(raw)
      → Uint8List → String（中文解码）
    → return Success(decodedHtml)
```

### 7.2.5 POST 请求链路

```dart
static Future<Resource> postForm(String url, {required Object? data, required CharsetsType charsetsType}) async {
  final response = await dio.post(
    url,
    data: data,
    options: Options(contentType: Headers.formUrlEncodedContentType),
  );
  // GBK/Big5 解码...
  return Success(decodedHtml);
}
```

**与 GET 的区别**：
- Content-Type: `application/x-www-form-urlencoded`
- data 参数：可以是 `Map<String, dynamic>` 或已编码的 `String`
- 不检查重定向（POST 请求通常不重定向）

### 7.3.3 搜索接口的编码链路

```dart
static Future<Resource> searchNovelByTitle({required String title, required int index}) {
  switch (charsetsType) {
    case CharsetsType.gbk:
      title = GbkEncoder().convert(title)
        .map((b) => '%${b.toRadixString(16).padLeft(2, '0').toUpperCase()}')
        .join();
    case CharsetsType.big5Hkscs:
      title = Big5Encoder().convert(title)
        .map((b) => '%${b.toRadixString(16).padLeft(2, '0').toUpperCase()}')
        .join();
  }
  final String url = "${wenku8Node.node}/modules/article/search.php?searchtype=articlename&searchkey=$title&page=$index";
  return Request.get(url, charsetsType: charsetsType);
}
```

**编码链路**：

```
搜索关键词 "异世界"
  → GbkEncoder().convert("异世界")
    → [0xD2, 0xEC, 0xCA, 0xC0, 0xBD, 0xE7]（GBK 字节流）
  → map() 每个字节转 %XX
    → "%D2%EC%CA%C0%BD%E7"
  → 拼接 URL
    → "https://www.wenku8.cc/modules/article/search.php?searchtype=articlename&searchkey=%D2%EC%CA%C0%BD%E7&page=1"
```

### 7.3.4 发表评论的编码链路

```dart
static Future<Resource> sendComment({required String aid, required String title, required String content}) {
  String submit;
  switch (charsetsType) {
    case CharsetsType.gbk:
      submit = GbkEncoder().convert("发表书评").map(...).join();  // 提交按钮文字
      title = title.gbkUrlEncodingIfNotAscii();                   // 标题（String 扩展）
      content = content.gbkUrlEncodingIfNotAscii();               // 内容（String 扩展）
    case CharsetsType.big5Hkscs:
      submit = Big5Encoder().convert("發表書評").map(...).join();
      title = title.big5UrlEncodingIfNotAscii();
      content = content.big5UrlEncodingIfNotAscii();
  }
  submit = "+$submit+";  // URL 编码的空格
  final String params = "ptitle=$title&pcontent=$content&Submit=$submit";
  return Request.postForm(url, data: params, charsetsType: charsetsType);
}
```

**编码链路**：

```
发表评论 aid="1234", title="好看", content="推荐这本书"

1. submit 按钮文字
   → GbkEncoder().convert("发表书评") → "%B7%A2%B1%ED%CA%E9%C6%C0"
   → "+%B7%A2%B1%ED%CA%E9%C6%C0+"

2. title 标题
   → "好看".gbkUrlEncodingIfNotAscii()
     → GbkCodec().encode("好看") → [0xBA, 0xC3, 0xBF, 0xB4]
     → _encode() → "%BA%C3%BF%B4"

3. content 内容
   → "推荐这本书".gbkUrlEncodingIfNotAscii()
     → GbkCodec().encode("推荐这本书") → [0xCD, 0xC6, 0xBC, 0xF6, 0xD5, 0xE2, 0xB1, 0xBE, 0xCA, 0xE9]
     → _encode() → "%CD%C6%BC%F6%D5%E2%B1%BE%CA%E9"

4. 拼接参数
   → "ptitle=%BA%C3%BF%B4&pcontent=%CD%C6%BC%F6%D5%E2%B1%BE%CA%E9&Submit=+%B7%A2%B1%ED%CA%E9%C6%C0+"

5. POST 发送
   → Request.postForm(url, data: params)
     → Content-Type: application/x-www-form-urlencoded
```

## 7.5 ChapterDownloader — 章节下载器

> 源码：`lib/network/chapter_downloader.dart`

### 7.5.1 状态管理

```dart
final Map<String, CancelToken> _cancelTokens = {};      // taskId → CancelToken
final Map<String, bool> _downloadingStatus = {};          // taskId → 是否下载中
```

每个任务通过 `taskId` 标识，独立管理取消令牌和下载状态。

### 7.5.2 下载链路

```dart
Future<String> download({
  required String taskId,
  required String aid,
  required String cid,
  Function(int received, int total)? onProgress,
}) async {
  // 1. 检查重复/取消
  if (isDownloading(taskId)) throw Exception('正在下载中');
  if (isCanceled(taskId)) throw Exception('已被取消');

  // 2. 标记状态 + 创建取消令牌
  _downloadingStatus[taskId] = true;
  final cancelToken = CancelToken();
  _cancelTokens[taskId] = cancelToken;

  // 3. 获取存储目录
  final dir = await getApplicationSupportDirectory();
  final cacheDir = Directory("${dir.path}/cached_chapter");
  final savePath = "${cacheDir.path}/${aid}_$cid.txt";

  // 4. 构造 URL
  var url = "${Api.wenku8Node.node}/modules/article/reader.php?aid=$aid&cid=$cid";
  url += "?charset=gbk";  // 或 big5

  // 5. 发起请求（带进度回调）
  final response = await _dio.get(url,
    cancelToken: cancelToken,
    onReceiveProgress: (received, total) => onProgress?.call(received, total),
  );

  // 6. GBK/Big5 解码
  String content = GbkCodec().decode(response.data as Uint8List);

  // 7. 写入文件
  final file = File(savePath);
  await file.writeAsString(content, flush: true);

  return savePath;
}
```

**完整链路**：

```
ChapterCacheController.startDownload(task)
  → ChapterDownloader.download(taskId, aid, cid, onProgress)
    → 检查 isDownloading(taskId) → 防重复
    → 检查 isCanceled(taskId) → 防无效下载
    → _downloadingStatus[taskId] = true
    → CancelToken() → _cancelTokens[taskId]
    → getApplicationSupportDirectory()
    → Directory("$path/cached_chapter")
    → 构造 URL: "https://www.wenku8.cc/modules/article/reader.php?aid=1234&cid=5678?charset=gbk"
    → Dio.get(url, cancelToken, onReceiveProgress)
      → CloudflareInterceptor → CookieManager → HTTP 请求
      → onReceiveProgress(received, total) → 回调通知 UI 进度
    → GbkCodec().decode(Uint8List) → String
    → File("$path/cached_chapter/1234_5678.txt").writeAsString(content)
    → return savePath
    → finally: 清理 _downloadingStatus 和 _cancelTokens
```

### 7.5.3 取消链路

```
用户点击取消
  → ChapterDownloader.cancel(taskId)
    → _cancelTokens[taskId].cancel('用户主动取消下载')
    → Dio 抛出 DioException(type: DioExceptionType.cancel)
    → download() catch 块捕获
    → throw Exception('canceled')
    → finally: 清理状态
```

## 7.6 ImageUrlHelper — 图片 URL 处理

> 源码：`lib/network/image_url_helper.dart`

### 7.6.1 normalize — 规范化

```dart
static String normalize(String src) {
  var s = src.trim();
  if (s.startsWith('//')) s = 'https:$s';           // 协议相对链接
  if (s.startsWith('/')) s = 'https://pic.wenku8.com$s';  // 路径相对链接
  if (uri.scheme == 'http') → 升级为 https            // http → https
  return s;
}
```

### 7.6.2 fallback — 兜底

```dart
static String fallback(String url) {
  if (host == 'pic.777743.xyz') → 替换为 'pic.wenku8.com'  // 镜像域名兜底
  return url;
}
```

**使用场景**：图片加载失败时，尝试用 `fallback()` 获取备用 URL 重新加载。

## 7.8 网络层设计总结

| 设计决策 | 原因 |
|----------|------|
| ResponseType.bytes | wenku8 使用 GBK/Big5 编码，需要原始字节解码 |
| followRedirects: false | 302 重定向需要手动拼接域名 |
| CloudflareInterceptor | wenku8 经常触发 Cloudflare 人机验证 |
| 静态方法设计 | Api/Parser 无状态，全局唯一，不需要实例化 |
| GBK/Big5 双编码支持 | 简体/繁体用户使用不同编码访问 wenku8 |
| ChapterDownloader 独立 | 下载任务需要取消、进度回调、状态管理，逻辑复杂 |
| ImageUrlHelper 兜底 | wenku8 镜像域名不稳定，需要备用方案 |
