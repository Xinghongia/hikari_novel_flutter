# 11 - 阅读器：核心体验模块

阅读器是整个应用的核心体验所在。controller.dart 管理阅读进度、章节切换和阅读设置。view.dart 组合了多种阅读组件：horizontal_read_page 和 vertical_read_page 分别实现横向翻页和纵向滚动两种阅读模式，paper_curl_pager 实现仿真翻页效果，reader_background 提供背景主题，reader_setting 管理字体/字号/行距等设置面板，tts_floating_controller 提供语音朗读悬浮控制。

---

## 一、模块结构

```
lib/pages/reader/
  ├─ controller.dart              ← 阅读器控制器（进度、章节、设置、字体、背景）
  ├─ view.dart                    ← 阅读器主视图（组合所有子组件）
  └─ widgets/
       ├─ horizontal_read_page.dart   ← 横向翻页阅读器（PageView + 仿真翻页）

       ├─ paper_curl_pager.dart       ← 仿真翻页效果（数学计算 + CustomPaint）

       ├─ custom_slider.dart          ← 自定义滑块
       └─ custom_header.dart          ← 自定义刷新头
```

### 2.2 初始化链路

```
onInit()
  │  ① 从 NovelDetailController 获取 aid 和 catalogue
  │  ② 监听电池电量变化
  │  ③ 加载文字颜色、背景颜色、背景图片（区分深浅模式）
  │  ④ 检查自定义字体文件是否存在
  │  ⑤ getInitLocation() — 解析路由参数中的阅读位置
  │  ⑥ debounce(currentLocation/currentIndex) → 150ms 后保存阅读记录
  │
  ▼
onReady()
  │  ① 如果 wakeLock 开启 → WakelockPlus.toggle(enable: true)
  │  ② 应用沉浸模式设置
  │  ③ 在 compute() 中查找 cid 在目录中的位置（避免主线程卡顿）
  │  ④ 设置 currentVolumeIndex 和 currentChapterIndex
  │  ⑤ getContent() — 加载章节内容
  │
  ▼
getContent()
  │  ① _getChapterContentFromLocal() — 先检查本地缓存
  │     → {supportDir}/cached_chapter/{aid}_{cid}.txt
  │  ② 如果有缓存 → _getContentByLocal()
  │  ③ 如果无缓存 → _getContentByNetwork()
  │
  ▼
_getContentByNetwork()
  │  ① Api.getNovelContent(aid, cid) — 请求章节 HTML
  │  ② Parser.isError() — 检查是否需要登录
  │  ③ compute(Parser.getContent, html) — 在隔离线程解析 HTML
  │     → Content(text, images)
  │  ④ text.value = content.text
  │  ⑤ images.value = content.images
  │  ⑥ pageState = success
```

**关键：** `compute()` 在独立 isolate 中执行 HTML 解析，避免阻塞 UI 线程。

### 2.3 章节切换

```dart
void nextChapter() {
  // 判断是否是最后一章
  if (currentVolumeIndex + 1 == currentVolumeTotal &&
      currentChapterIndex + 1 == currentChapterTotal) {
    // 弹窗提示"没有下一章"
    Get.dialog(AlertDialog(content: "no_next_chapter".tr));
  } else {
    // 跨卷：当前卷最后一章 → 下一卷第一章
    if (currentChapterIndex + 1 == currentChapterTotal) {
      currentVolumeIndex++;
      currentChapterIndex = 0;
    } else {
      currentChapterIndex++;
    }
    clearInitLocation();  // 重置阅读位置
    getContent();          // 加载新章节
  }
}

void prevChapter() {
  // 判断是否是第一章
  if (currentVolumeIndex == 0 && currentChapterIndex == 0) {
    Get.dialog(AlertDialog(content: "no_previous_chapter".tr));
  } else {
    // 跨卷：当前卷第一章 → 上一卷最后一章
    if (currentChapterIndex == 0) {
      currentVolumeIndex--;
      currentChapterIndex = currentChapterTotal - 1;
    } else {
      currentChapterIndex--;
    }
    clearInitLocation();
    getContent();
  }
}
```

### 2.4 翻页控制

```dart
void nextPage() {
  if (currentIndex.value >= maxPage.value - 1) {
    nextChapter();       // 最后一页 → 下一章
  } else {
    jumpToPage(currentIndex.value + 1);
  }
}

void prevPage() {
  if (currentIndex.value == 0) {
    prevChapter();       // 第一页 → 上一章
  } else {
    jumpToPage(currentIndex.value - 1);
  }
}

void jumpToPage(int page) {
  if (direction != upToDown && pageTurningAnimation) {
    paperCurlController.jumpToPage(page);  // 仿真翻页
    return;
  }
  pageTurningAnimation
    ? pageController.animateToPage(page, duration: 200ms)  // 动画翻页
    : pageController.jumpToPage(page);                      // 直接跳转
}
```

### 2.5 阅读记录保存

```dart
// debounce 机制：150ms 内没有新变化才保存
debounce(currentLocation, (_) => setReadHistory(), time: 150ms);
debounce(currentIndex, (_) => setReadHistory(), time: 150ms);

void setReadHistory() async {
  await DBService.instance.upsertReadHistory(
    ReadHistoryEntityData(
      cid: cid,
      aid: aid,
      readerMode: direction == upToDown ? kScrollReadMode : kPageReadMode,
      isDualPage: isDualPage,
      location: direction == upToDown ? currentLocation.value : currentIndex.value,
      progress: direction == upToDown ? verticalProgress.value : horizontalProgress.value,
      isLatest: true,
    ),
  );
}
```

**关键：** 用 `debounce` 而不是每次滚动/翻页都保存，避免频繁写数据库。

## 四、HorizontalReadPage — 横向翻页

### 4.1 核心流程

```
文本输入 → initPage() → splitText() → pages 列表 → PageView / PaperCurlPager
```

**splitText() — 文本分页算法（在 compute isolate 中执行）：**

```
① 计算各种字符宽度：中文、英文、标点、空格
② 计算每页最大行数：pageHeight / fontHeight
③ 按段落分割文本（\n\n 分隔）
④ 每段落按行拆分：
   - 第一行加缩进（paraIndent 个全角空格）
   - 逐字符计算宽度，超过 pageWidth 则换行
⑤ 按页收集行：
   - 累计高度超过 pageHeight → 新页
   - 段落末尾额外加 paraSpacing
⑥ 图片单独占一页
```

**结果：** `List<Page>`，每个 Page 是 `TextPage(rows)` 或 `ImagePage(url)`。

### 4.2 单页 vs 双页

```dart
// 单页：一个 PageView item = 一页文本/图片
Widget _buildSingleText(int index) {
  return CustomPaint(
    painter: NovelTextPainter(rows, style, fontHeight, paraSpacing),
  );
}

// 双页：一个 PageView item = 两页文本并排
Widget _buildDualPage(int i) {
  return Row([
    Expanded(child: _buildDualSideText(i * 2)),      // 左页
    SizedBox(width: dualPageSpacing),                   // 书脊间隙
    Expanded(child: _buildDualSideText(i * 2 + 1)),   // 右页
  ]);
}
```

### 4.3 点击区域

```dart
onTapUp: (details) {
  final logicalX = reverse ? (width - dx).clamp(0, width) : dx;
  if (logicalX <= width * 0.28) → onLeftTap();     // 左 28%：上一页
```

### 4.4 布局签名（Layout Signature）

```dart
String _layoutSignature() {
  return [text.length, images.length, isDualPage, dualPageSpacing,
          size.width, size.height, fontSize, height, ...].join("|");
}
```

当布局参数变化时（字号、行距、窗口大小等），重新分页。用签名比较而不是对象比较，避免深浅模式切换时误判。

### 4.5 NovelTextPainter — 自定义文本绘制

```dart
class NovelTextPainter extends CustomPainter {
  void paint(Canvas canvas, Size size) {
    double y = 0;
    for (final row in rows) {
      TextPainter(text: TextSpan(text: row.text, style: style), maxLines: 1, textAlign: justify)
        ..layout(maxWidth: size.width)
        ..paint(canvas, Offset(0, y));
      y += fontHeight;
      if (row.paragraphEnd) y += paragraphSpacing;  // 段落末尾额外间距
    }
  }
}
```

**为什么用 CustomPaint 而不是 RichText？** 精确控制每行位置，实现分页效果。

## 六、PaperCurlPager — 仿真翻页

### 6.1 核心原理

基于几何数学计算纸张折叠效果：

```
┌─────────────────────────┐
│                         │
│    当前页 (page[index]) │
│                         │
│         A←──────────折叠点
│        ╱ ╲              │
│       ╱   ╲             │
│      ╱     ╲            │
│     ╱  折叠区 ╲           │
│    ╱         ╲          │
│   F───────────E         │
│                         │
│    下一页 (page[index+1])│
│                         │
└─────────────────────────┘
```

**_PaperPoint** 类计算所有几何点（A、B、C、D、E、F、G、H、I、J、K、P1、P2），包括：
- 纸张折叠的贝塞尔曲线
- 阴影投射
- 背面显示

### 6.2 交互方式

```dart
// 点击翻页
_handleTap(details) {
  if (左侧 28%) → _animatePrev(fromTop);
  if (右侧 28%) → _animateNext(fromTop);
  else → onCenterTap();
}

// 拖拽翻页
_handlePanUpdate(details) {
  // 更新纸张折叠点 A 的位置
  // 计算是否翻页（_isForward = 拖拽距离 > 33%）
}

_handlePanEnd(details) {
  if (_isForward) → _controller.forward();  // 完成翻页动画
  else → _resetToIdle();                     // 回弹
}
```

## 十、总结

### 10.1 核心职责

ReaderController 管理阅读器的全部状态：
- **阅读进度**：横向用页码，纵向用像素偏移，debounce 保存
- **章节切换**：跨卷逻辑（上一卷末 ↔ 下一卷首）
- **内容加载**：本地缓存优先 → 网络请求 → compute 解析
- **设置管理**：不可变对象 + copyWith + LocalStorageService 持久化
- **主题系统**：区分深浅模式，支持自定义字体/颜色/背景图片
- **系统控制**：沉浸模式、屏幕常亮

### 10.2 两种阅读模式对比

| 维度 | HorizontalReadPage | VerticalReadPage |
|------|-------------------|-----------------|
| 布局 | PageView / PaperCurlPager | CustomScrollView + SliverList |
| 分页 | 需要分页算法（compute isolate） | 不需要，自然流式 |
| 位置记录 | 页码（int） | 像素偏移（double） |
| 进度 | 页码/总页数 | 百分比 |
| 双页 | 支持（两页并排） | 不支持 |
| 仿真翻页 | 支持（PaperCurlPager） | 不支持 |
| 文本渲染 | CustomPaint（NovelTextPainter） | RichText |
| 章节切换 | EasyRefresh 上拉/下拉 | EasyRefresh 上拉/下拉 |

### 10.3 关键设计模式

| 模式 | 应用场景 | 效果 |
|------|---------|------|
| compute isolate | HTML 解析、文本分页 | 不阻塞 UI 线程 |
| debounce | 阅读进度保存 | 150ms 内无变化才写数据库 |
| 不可变设置 + copyWith | ReaderSettingsState | 响应式更新，状态可追溯 |
| 布局签名 | HorizontalReadPage/VerticalReadPage | 参数变化时重新排版 |
| 本地缓存优先 | 章节内容加载 | 缓存章节秒开 |
| ExcludeSemantics | ReaderPage 整体 | 防止 Windows 无障碍崩溃 |
| _isClosed 生命周期保护 | Controller | 防止 dispose 后更新状态 |
| AnimatedPositioned | 操作栏显隐 | 平滑动画 |
| 自定义 CustomPaint | 仿真翻页、文本绘制 | 精确控制渲染 |
| 分段朗读 | TTS | 避免超长文本朗读失败 |

### 10.4 数据流总览

```
NovelDetailPage 点击章节
  │  Get.toNamed(reader, parameters: {cid, location})
  │
  ▼
ReaderController.onReady()
  │  compute(查找 cid 位置) → currentVolumeIndex, currentChapterIndex
  │  getContent()
  │    ├─ 本地缓存 → _getContentByLocal()
  │    └─ 网络请求 → _getContentByNetwork() → compute(Parser.getContent)
  │
  ▼
text.value + images.value 更新
  │
  ├─ 方向 = upToDown → VerticalReadPage
  │    └─ CustomScrollView → 滚动监听 → currentLocation/verticalProgress
  │
  └─ 方向 = leftToRight/rightToLeft → HorizontalReadPage
       └─ compute(splitText) → pages → PageView / PaperCurlPager
            └─ 翻页监听 → currentIndex/horizontalProgress
  │
  ▼
debounce(150ms) → setReadHistory() → DBService.upsertReadHistory()
  │
  ▼
用户返回 NovelDetailPage
  │  StreamBuilder 监听阅读历史变化 → 目录自动刷新进度
  │  StreamBuilder 监听最新阅读记录 → 继续阅读 FAB 更新
```
