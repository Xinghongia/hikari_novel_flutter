# 14 - 平台配置与构建系统

平台配置层包含 Android、iOS、Windows、Linux、macOS 和 Web 六个平台的原生代码和构建配置。Android 端的 MainActivity.kt 通过 MethodChannel 提供 TTS 设置和应用启动的原生桥接。各平台的入口文件（main.cpp、main.cc、AppDelegate.swift）负责初始化 Flutter 引擎并注册插件。构建系统使用 Gradle（Android）、CMake（Windows/Linux）和 Xcode（iOS/macOS）三套工具链。

---

## 一、项目目录结构

```
hikari_novel_flutter/
  ├─ android/          ← Android 平台（Gradle + Kotlin）
```

## 二、Android 平台

### 2.1 入口文件

```kotlin
// android/app/src/main/kotlin/pers/cyh128/hikari_novel/MainActivity.kt
class MainActivity : FlutterActivity() {
    override fun configureFlutterEngine(@NonNull flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)

        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, "hikari/system_intents")
            .setMethodCallHandler { call, result ->
                when (call.method) {
                    "openTtsSettings" -> { /* 打开系统 TTS 设置 */ }
                    "openApp" -> { /* 打开指定应用 */ }
                    else -> result.notImplemented()
                }
            }
    }
}
```

### 2.2 MethodChannel 桥接

| 方法 | 作用 | Dart 调用方 |
|------|------|------------|
| `openTtsSettings` | 打开系统 TTS 设置页面 | `TtsService.openAndroidTtsSettings()` |
| `openApp` | 通过包名启动其他应用 | `TtsService.openAndroidApp(packageName)` |

**`openTtsSettings` 的实现：** 尝试 3 个 Intent Action，兼容不同厂商：
```kotlin
val candidates = arrayListOf(
    Intent("android.speech.tts.engine.TTS_SETTINGS"),      // 标准
    Intent("com.android.settings.TTS_SETTINGS"),            // 部分厂商
    Intent(android.provider.Settings.ACTION_SETTINGS)       // 回退到系统设置
)
```

### 2.3 AndroidManifest.xml

```xml
<manifest>
    <uses-permission android:name="android.permission.INTERNET"/>

    <application android:label="Hikari Novel" android:icon="@mipmap/launcher_icon">
        <activity android:name=".MainActivity"
            android:exported="true"
            android:launchMode="singleTop"
            android:theme="@style/LaunchTheme"
            android:hardwareAccelerated="true">
            <meta-data android:name="io.flutter.embedding.android.NormalTheme"
                android:resource="@style/NormalTheme"/>
            <intent-filter>
                <action android:name="android.intent.action.MAIN"/>
                <category android:name="android.intent.category.LAUNCHER"/>
            </intent-filter>
        </activity>
        <meta-data android:name="flutterEmbedding" android:value="2"/>
    </application>

    <!-- 包可见性声明（Android 11+） -->
    <queries>
        <intent><action android:name="android.intent.action.PROCESS_TEXT"/></intent>
        <intent><action android:name="android.intent.action.TTS_SERVICE"/></intent>
        <package android:name="org.nobody.multitts"/>
    </queries>
</manifest>
```

**关键配置：**
- `INTERNET` 权限：网络请求
- `flutterEmbedding = 2`：使用 V2 嵌入 API
- `queries` 声明：Android 11+ 包可见性，允许查询 TTS 引擎和 MultiTTS 应用

```swift
@main
@objc class AppDelegate: FlutterAppDelegate {
  override func application(
    _ application: UIApplication,
```

## 四、Windows 平台

### 4.1 入口文件

```cpp
// windows/runner/main.cpp
int APIENTRY wWinMain(_In_ HINSTANCE instance, ...) {
  // 附加到控制台（调试用）
  if (!::AttachConsole(ATTACH_PARENT_PROCESS) && ::IsDebuggerPresent()) {
    CreateAndAttachConsole();
  }

  // 初始化 COM（WebView2 等插件需要）
  ::CoInitializeEx(nullptr, COINIT_APARTMENTTHREADED);

  flutter::DartProject project(L"data");
  FlutterWindow window(project);

  Win32Window::Size size(1280, 720);  // 默认窗口大小
  window.Create(L"hikari_novel_flutter", origin, size);
  window.SetQuitOnClose(true);

  // Win32 消息循环
  ::MSG msg;
  while (::GetMessage(&msg, nullptr, 0, 0)) {
    ::TranslateMessage(&msg);
    ::DispatchMessage(&msg);
  }

  ::CoUninitialize();
  return EXIT_SUCCESS;
}
```

### 4.2 构建配置

```cmake
# windows/CMakeLists.txt
cmake_minimum_required(VERSION 3.14)
project(hikari_novel_flutter LANGUAGES CXX)

set(BINARY_NAME "hikari_novel_flutter")

# C++17 标准
function(APPLY_STANDARD_SETTINGS TARGET)
  target_compile_features(${TARGET} PUBLIC cxx_std_17)
  target_compile_options(${TARGET} PRIVATE /W4 /WX /wd"4100")
endfunction()

# 安装规则
set(CMAKE_INSTALL_PREFIX "${BUILD_BUNDLE_DIR}")
install(TARGETS ${BINARY_NAME} RUNTIME DESTINATION ...)
install(FILES "${FLUTTER_ICU_DATA_FILE}" DESTINATION "${INSTALL_BUNDLE_DATA_DIR}")
install(FILES "${FLUTTER_LIBRARY}" DESTINATION "${INSTALL_BUNDLE_LIB_DIR}")
```

### 4.3 安装器

Windows 平台包含 `installer.iss`（Inno Setup 脚本），用于生成 Windows 安装程序（.exe）。


## 九、原生桥接架构

```
Dart 层                    MethodChannel               原生层
─────────                  ─────────────               ──────
TtsService                 "hikari/system_intents"     MainActivity.kt
  .openAndroidTtsSettings  ──────────────────────→       openTtsSettings
  .openAndroidApp(pkg)     ──────────────────────→       openApp(pkg)
```

目前只有 Android 端有自定义 MethodChannel。其他平台的原生代码是 Flutter 模板生成的默认实现，仅负责初始化引擎和注册插件。

## 十、总结

### 10.1 核心职责

| 层 | 职责 |
|----|------|
| 原生入口 | 初始化 Flutter 引擎、注册插件、启动消息循环 |
| MethodChannel | Dart ↔ 原生双向通信（目前仅 Android TTS 设置） |
| 构建配置 | 编译选项、签名、安装规则、版本号管理 |
| 平台清单 | 权限声明、包可见性、应用元数据 |

### 10.2 各平台差异

| 特性 | Android | iOS | Windows | Linux | macOS | Web |
|------|---------|-----|---------|-------|-------|-----|
| 动态取色 | ✅ Material You | ❌ | ❌ | ❌ | ❌ | ❌ |
| TTS 桥接 | ✅ MethodChannel | 系统默认 | 系统默认 | 系统默认 | 系统默认 | ❌ |
| 安装器 | APK/AAB | IPA | Inno Setup | - | DMG | PWA |
| WebView | InAppWebView | InAppWebView | WebView2 | - | - | - |
| 窗口管理 | 系统 | 系统 | Win32 API | GTK | NSWindow | 浏览器 |
