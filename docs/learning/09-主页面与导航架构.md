## 一、应用启动完整链路

```
App 启动
  │
  ▼
main.dart → GetMaterialApp(
  initialRoute: RoutePath.welcome,     // 首先进入欢迎页
  getPages: AppRoutes.mainRoutePages,  // 7 个主路由
)
  │
  ▼
WelcomePage（欢迎页）
  │  显示 Logo、欢迎文字、登录按钮、节点选择
  │  不检查登录状态，任何人都能看到
  │
  ▼
用户点击"前往登录" → Get.toNamed(RoutePath.login)
  │
  ▼
LoginPage（WebView 登录页）
  │  加载 wenku8 的 login.php
  │  用户在 WebView 中输入账号密码
  │  登录成功后 WebView 跳转到 wenku8 首页
  │
  ▼
LoginController.saveCookie(WebUri uri)
  │  ① 检测 URL 是否包含 "wenku8"
  │  ② 获取 Cookie，检查是否包含 "jieqiUserInfo" 和 "jieqiVisitInfo"
  │  ③ 拼接 Cookie 字符串并存储到 LocalStorageService
  │  ④ Request.initCookie() 初始化请求 Cookie
  │  ⑤ _getUserInfo() 获取用户信息并存储
  │  ⑥ _refreshBookshelf() 刷新全部 6 个书架分类到本地数据库
  │
  ▼
Get.offAllNamed(RoutePath.main)  // 清空导航栈，跳转主页
  │
  ▼
MainPage（主界面壳布局）
```

**关键代码：**

```dart
// lib/pages/login/controller.dart
Future<void> saveCookie(WebUri uri) async {
  if (uri.toString().contains("wenku8") == true) {
    final getCookie = await cookieManager.getCookies(url: uri);

    // 检查必需的 Cookie
    bool hasCookie = ["jieqiUserInfo", "jieqiVisitInfo"].every(
      (keyword) => getCookie.any((cookieItem) => cookieItem.name.contains(keyword)),
    );

    if (hasCookie) {
      // 拼接并存储 Cookie
      String cookie = "jieqiUserInfo=${...};jieqiVisitInfo=${...}";
      LocalStorageService.instance.setCookie(cookie);
      Request.initCookie();

      // 获取用户信息 + 刷新书架
      await _getUserInfo();
      await _refreshBookshelf();

      // 跳转主页（清空整个导航栈）
      Get.offAllNamed(RoutePath.main);
    }
  }
}
```

- 书架多选模式时底部栏替换为批量操作栏

## 三、子路由 Navigator

### 3.1 创建

```dart
// lib/pages/main/view.dart
Widget _buildContentNavigator(MainController controller) {
  return PopScope(
    canPop: false,                              // 拦截返回键
    onPopInvokedWithResult: (didPop, _) {
      if (!didPop) {
        // ① 优先处理 NovelDetail 的多选模式退出
        try {
          NovelDetailController novelDetailController = Get.find();
          if (novelDetailController.isSelectionMode.value) {
            novelDetailController.exitSelectionMode();
            return;
          }
        } catch (_, _) {}

        // ② 尝试主导航器 pop
        if (Navigator.canPop(Get.context!)) {
          Get.back();
          return;
        }
        // ③ 尝试子导航器 pop
        else if (AppSubRouter.subNavigatorKey!.currentState!.canPop()) {
          AppSubRouter.subNavigatorKey!.currentState!.pop();
          return;
        }
      }
    },
    child: ClipRect(                            // 裁剪超出区域
      child: Navigator(
        key: AppSubRouter.subNavigatorKey,      // GlobalKey，用于手动操作
        initialRoute: RoutePath.logo,            // 默认显示 LogoPage
        observers: [SubNavigatorObserver()],     // 监听路由变化
        onGenerateRoute: (settings) => AppRoutes.subRoutePages(settings),
      ),
    ),
  );
}
```

**返回键处理链（优先级从高到低）：**
1. NovelDetail 多选模式 → 退出多选
2. 主导航器可以 pop → `Get.back()`
3. 子导航器可以 pop → `subNavigatorKey.currentState!.pop()`

### 3.2 SubNavigatorObserver — 路由监听

```dart
class SubNavigatorObserver extends NavigatorObserver {
  @override
  void didPush(Route route, Route? previousRoute) {
    super.didPush(route, previousRoute);
    if (previousRoute != null) {
      var routeName = route.settings.name ?? "";
      AppSubRouter.currentContentRouteName = routeName;
      // push 非 logo 页面时显示内容区
      Get.find<MainController>().showContent.value = routeName != RoutePath.logo;
    }
  }

  @override
  void didPop(Route route, Route? previousRoute) {
    super.didPop(route, previousRoute);
    var routeName = previousRoute?.settings.name ?? "";
    AppSubRouter.currentContentRouteName = routeName;
    // pop 回 logo 页面时隐藏内容区
    Get.find<MainController>().showContent.value = routeName != RoutePath.logo;
  }
}
```

**效果：**
- `push("/novel_detail")` → `showContent = true` → 内容区显示
- `pop()` 回到 `"/logo"` → `showContent = false` → 内容区隐藏

### 5.1 登录检查

```dart
class BookshelfPage extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final isLoggedIn = LocalStorageService.instance.getCookie() != null;

    if (!isLoggedIn) {
      return _buildLoginPrompt(context);   // 未登录 → 显示登录提示
    }

    return PopScope(
      canPop: false,
      onPopInvokedWithResult: (didPop, _) {

          currentTabController.exitSelectionMode();
          return;

        // ③ 正常 → 交给上层处理
        Get.back();
      },
      child: Stack(
        children: [
          // 书架内容（6个分类 tab）
          Obx(() => Offstage(
            offstage: controller.pageState.value != PageState.bookshelfContent,
            child: _buildBookshelfContent(context),
          )),
          // 书架搜索
          Obx(() => Offstage(
            offstage: controller.pageState.value != PageState.bookshelfSearch,
            child: BookshelfSearchView(),
          )),
        ],
      ),
    );
  }
}
```

### 5.4 BookshelfContentController — 单个分类的控制器

```dart
class BookshelfContentController extends GetxController {
  final String classId;
  final BookshelfController _bookshelfController = Get.find();
  final MainController _mainController = Get.find();

  Rxn<Bookshelf> bookshelf = Rxn();
  Rx<PageState> pageState = Rx(PageState.loading);

  @override
  void onReady() {
    super.onReady();
    // 监听本地数据库的变化（实时同步）
    DBService.instance.getBookshelfByClassId(classId).listen((bss) async {
      List<BookshelfNovelInfo> list = bss.map((i) => BookshelfNovelInfo(...)).toList();
      if (list.isEmpty) {
        bookshelf.value = null;
        pageState.value = PageState.empty;
      } else {
        bookshelf.value = Bookshelf(list: list, classId: classId);
        pageState.value = PageState.success;
      }
    });
  }

  // 多选操作
  void enterSelectionMode() {
    _bookshelfController.isSelectionMode.value = true;
    _mainController.showBookshelfBottomActionBar.value = true;  // 替换主页面底部栏
  }

  void exitSelectionMode() {
    _bookshelfController.isSelectionMode.value = false;
    _mainController.showBookshelfBottomActionBar.value = false;
    deselect();
  }
}
```

**关键设计：** 书架数据来自本地数据库（drift），通过 `listen()` 实时监听变化。登录时 `LoginController._refreshBookshelf()` 会把网络数据同步到数据库，书架页面自动收到更新。

```
  │  HomePage → RecommendController.onReady() → getRecommend()
  │  → API 返回错误页（无 Cookie）
  │  → Parser.isError() = true
  │  → pageState = needLogin → 显示登录提示
  │
  ▼
BookshelfPage → 检测到无 Cookie → 直接显示登录提示
MyPage → 检测到无 Cookie → 直接显示登录提示
```

## 八、关键设计总结

| 设计 | 解决的问题 | 代码位置 |
|------|-----------|---------|
| `IndexedStack` | 切换 tab 不重建子页面，保持状态 | main/view.dart |
| `Stack` + `Offstage` | 子路由叠加在底部导航之上 | main/view.dart |
| `isLargeScreen()` | 响应式布局：底部栏 ↔ 侧边栏 | common/extension.dart |
| `PopScope` | 返回键优先级：多选退出 > 主 pop > 子 pop | main/view.dart |
| `SubNavigatorObserver` | 路由变化自动显隐内容区 | main/view.dart |
| `Get.offAllNamed` | 登录/退出时清空导航栈 | login/controller.dart |
| `everAll` 监听 | 条件满足后自动触发加载 | category/ranking controller |
| 本地数据库 `listen()` | 书架数据实时同步 | bookshelf/controller.dart |
| `showBookshelfBottomActionBar` | 书架多选时替换主页面底部栏 | main/controller.dart |
