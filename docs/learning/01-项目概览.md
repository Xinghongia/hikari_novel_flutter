# 01 - 项目概览

## Hikari Novel 是什么

Hikari Novel 是一款跨平台轻小说阅读器，数据源来自 [wenku8](https://www.wenku8.net/)（轻小说文库）。它的核心能力是：**抓取 wenku8 网页内容，解析成结构化小说数据，提供舒适的阅读体验**。

### 它解决了什么问题

看轻小说的痛点：wenku8 网页版体验差、广告多、不能离线看、没有朗读功能。Hikari Novel 把这些问题一次性解决了：

```
用户视角：
  浏览推荐/排行/分类 → 搜索小说 → 阅读章节 → 加入书架 → 离线缓存 → TTS 朗读

技术视角：
  Dio 请求 wenku8 → HTML 解析器提取内容 → GetX 状态管理 → 多种阅读模式渲染
```

### 核心特性

| 特性 | 说明 |
|------|------|
| 多源抓取 | 直接解析 wenku8 网页，提取小说列表、详情、章节内容 |
| 多种阅读模式 | 水平翻页、垂直滚动、仿真翻页（纸张卷曲效果） |
| TTS 朗读 | flutter_tts 文字转语音，支持后台朗读 |
| 书架管理 | 本地书架 + wenku8 网络书架同步 |
| 离线缓存 | 章节内容本地缓存，无网也能看 |
| 登录系统 | WebView 登录 wenku8，Cookie 持久化 |
| 动态取色 | Android 12+ Material You 动态颜色 |
| 跨平台 | 一套 Dart 代码，五平台运行 |

## 技术栈

| 类别 | 技术选型 | 说明 |
|------|----------|------|
| 框架 | Flutter 3.10.7+, Dart 3.10.7 | 跨平台 UI 框架 |
| 路由/DI/状态 | **GetX** | 一体化方案（路由 + 状态管理 + 依赖注入） |
| 网络 | Dio + Cookie 管理 | HTTP 客户端 |
| 键值存储 | Hive CE | 轻量级 NoSQL（设置、缓存状态） |
| 关系数据库 | **Drift** (SQLite ORM) | 结构化数据（书架、历史、阅读进度） |
| HTML 解析 | html 包 | 解析 wenku8 网页 |
| WebView | flutter_inappwebview | 登录页面加载 |
| TTS | flutter_tts | 文字转语音 |
| 时间处理 | Jiffy | 时间格式化 + 本地化 |
| 刷新组件 | EasyRefresh | 下拉刷新 + 上拉加载 |

## 核心数据流

### 浏览到阅读的完整链路

```
用户打开首页
    ↓
RecommendController.getRecommend()
    ↓ Dio GET 请求 wenku8
Api.getRecommend()
    ↓
Parser.getRecommend(html)  ← HTML 解析提取推荐板块列表
    ↓ 返回 List<RecommendBlock>
GetX Controller 更新状态
    ↓ 响应式
RecommendView UI 渲染推荐板块
    ↓ 用户点击小说
Get.toNamed(RoutePath.novelDetail, arguments: aid)
    ↓
NovelDetailController → Api.getNovelDetail(aid)
    ↓ Dio GET + HTML 解析
Parser.getNovelDetail(html)  ← 提取标题、作者、简介、章节列表
    ↓ 返回 NovelDetail
NovelDetailPage 渲染详情 + 章节列表
    ↓ 用户点击章节
ReaderController.getContent()
    ↓ 优先本地缓存，无缓存则网络请求
Api.getNovelContent(aid: aid, cid: cid)
    ↓ Dio GET + HTML 解析
Parser.getContent(html)  ← 提取章节正文文本
    ↓ 返回 Content
ReaderView 渲染文本（水平/垂直/仿真翻页）
    ↓ 同时：TtsService 可选朗读
```

### 书架同步链路

```
用户登录 wenku8（WebView）
    ↓ Cookie 保存到本地
BookshelfController.refreshBookshelf()
    ↓ 循环 6 个分类
Api.getBookshelf(classId: index)
    ↓ Dio GET + Cookie
Parser.getBookshelf(html, classId)  ← 解析网络书架
    ↓
DBService.insertAllBookshelf()  ← 写入 Drift 数据库
    ↓
BookshelfContentController 监听 Drift 数据流
    ↓ 响应式
BookshelfView 显示书架
```

## 核心设计模式

| 模式 | 应用场景 | 说明 |
|------|----------|------|
| GetX 全局服务 | DBService、LocalStorageService、TtsService | Get.put() 注册，全局单例 |
| GetX 响应式 | .obs + Obx() | 状态变化自动刷新 UI |
| GetX 路由 | GetPage + Get.toNamed() | 声明式路由 |
| MVC 分层 | pages/xxx/controller.dart + view.dart | 控制器与视图分离 |
| 基类抽象 | BaseListPageController | 列表分页逻辑复用 |
| HTML 解析器 | Parser 类 | 集中解析 wenku8 网页 |
| 双数据库 | Hive（键值） + Drift（关系） | 各司其职 |

## 学习路线建议

学习章节由你来定，下面是建议的切入点：

```
入门：从 main.dart 开始，理解 GetX 的路由、状态管理、DI 是怎么组织的
网络：看 network/ 层，理解 Dio 请求 + HTML 解析的流程
数据：看 models/ 和 common/database/，理解 Hive + Drift 双存储
页面：看 pages/ 下任意一个页面，理解 controller + view 的 GetX 模式
核心：看 reader/ 阅读器，这是项目最复杂的部分
```
